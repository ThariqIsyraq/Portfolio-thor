# Thariq Isyraq | Digital Creator Portfolio

A sleek, responsive personal portfolio website designed to showcase digital content creation, video editing, and graphic design projects. Built with a modern dark theme and interactive UI elements.

## 🚀 Features

*   **Modern Dark UI:** Clean, slate-themed background with vibrant cyan and purple accents.
*   **Fully Responsive:** Mobile-first design that looks great on desktops, tablets, and smartphones.
*   **Glassmorphism Navigation:** Fixed, blurred navigation bar for seamless scrolling.
*   **Video Integration:** Built-in HTML5 video players optimized for vertical (9:16) short-form content.
*   **Interactive Design Carousel:** Smooth, horizontal-scrolling image gallery for graphic design assets.
*   **Hover Animations:** Custom CSS transform and shadow effects for interactive elements.

## 🛠️ Tech Stack

*   **HTML5:** Semantic markup and structure.
*   **Tailwind CSS (CDN):** Utility-first styling for rapid UI development.
*   **Font Awesome:** Scalable vector icons for social links and UI elements.
*   **Google Fonts:** Utilizing 'Montserrat' for clean, professional typography.
